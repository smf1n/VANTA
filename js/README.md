# VANTA

3D-шутер от третьего лица на чистом HTML5 + Three.js. Без сервера, без онлайна — всё работает в браузере.

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| W A S D | Движение |
| Мышь | Поворот камеры |
| ЛКМ | Стрельба |
| Shift | Бег |
| 1 / 2 / 3 / 4 | Пистолет / Автомат / Дробовик / Снайперка |
| R | Перезарядка |
| Esc | Пауза |

## 🗺 Карты
- Арена — открытая, для снайперки и автомата
- Город — средняя, универсальная
- Бункер — тесная, для дробовика и пистолета

## 👤 Персонажи
- Разведчик — быстрый, но хрупкий (80 HP, скорость 7)
- Солдат — баланс (120 HP, скорость 5.6)
- Тяжёлый — танк (180 HP, скорость 4)

## ⚔ Оружие
| Оружие | Урон | Магазин | Особенность |
|--------|------|---------|-------------|
| Пистолет | 22 | 12 | Точный стартовый |
| Автомат | 16 | 30 | Автоогонь |
| Дробовик | 13×8 | 6 | Ближний бой |
| Снайперка | 90 | 5 | Один выстрел — один труп |

## 🎯 Сложности
- Лёгкая — медленные, не меткие, долго реагируют
- Средняя — прицеливаются, держат дистанцию, стрейфят
- Сложная — умные, отступают при низком HP, меткие

## 🚀 Как запустить

Игра использует ES-модули, поэтому двойной клик по `index.html` не сработает — нужен локальный сервер.

### VS Code + Live Server (рекомендую)
1. Установи расширение Live Server
2. Открой папку проекта в VS Code
3. Правый клик на `index.html` → Open with Live Server
